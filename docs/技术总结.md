# 技术总结（实战记录）

> 基于 2026-08 一次真实操作沉淀：一加 Ace 5 Pro 通过 USB(MTP) 连接，完成"查音乐 → 导出 → 转 mp3 → 推送铃声"全流程。

## 1. 手机连接的两种方式

### 1.1 MTP（本工具主路径）
- 手机上选 **文件传输/MTP** 模式连接
- Windows 里设备以「便携设备(WPD)」出现，类名 `WPD`，无需驱动
- 用 `Shell.Application` COM 的 `Namespace(17)`（我的电脑）枚举设备：

```powershell
$shell = New-Object -ComObject Shell.Application
$hosts = $shell.Namespace(17)          # 17 = 我的电脑
foreach ($d in $hosts.Items()) { $d.Name }   # 如 "一加 Ace 5 Pro"
```

- 进入存储：设备根 `GetFolder()` → 内部存储 → 根目录；递归用 `item.GetFolder()`，能拿到 folder 则它是目录，否则是文件。
- **判断目录 vs 文件**：`try { $item.GetFolder }` 能返回就说明是目录。
- **写文件（推铃声）**：`$destFolder.CopyHere($localPath, 0x814)`，0x814 = `0x800`(允许撤销)+`0x10`(不显示UI)+`0x4`(不显示进度)。
- **导出文件**：拿到 MTP item 后 `$localDir.CopyHere($srcItem, 0x814)`。
- **删除**：`$item.InvokeVerb('delete')` 有时弹确认框卡住，需改善（可让用户在文件管理器删）。

### 1.2 adb
- 需要手机开 **开发者选项 → USB 调试**，再在弹出窗口授权
- 本机可用 `adb.exe` 在雷电模拟器目录：`D:\game\leidian\LDPlayer14\adb.exe`
- 未开 USB 调试时 `adb devices` 看不到真机
- adb 才能访问 **app 私有目录**（`/data/data/...`）和**系统 data 分区**，MTP 看不到

## 2. 手机音频/铃声在哪些位置

MTP 可见的内部存储根目录常见：
- `Music/` —— 音乐
- `Ringtones/` —— 铃声（**放 mp3 进去会自动进铃声列表**）
- `Notifications/` —— 通知音
- `Alarms/` —— 闹钟音
- `Recordings/` —— 通话/录音
- `Download/` —— 下载（网易云等下载的音乐常在这）
- `ColorOS/` —— 一加/Oplus 系统目录（本次为空）

### 关键发现
- **标准铃声目录常是空的**：客服下载的铃声可能存 app 私有或系统分区，MTP 看不到
- 本次在 `Download\netease\cloudmusic\Music\` 找到 4 个 `.ncm` + 1 个 `.mp3`
- "阳光下的星星"能在铃声列表看到但标准目录找不到 → 存系统分区，需 adb

## 3. 网易云 .ncm 转换

`.ncm` 是网易云加密格式，结构：头部 + RC4 加密的 key + 元数据(含 `format` 字段) + 封面 + RC4 流加密的音频。

### 工具
- Python 库 `ncmdump`（含解密）：`.ncm` → 原始音频（**mp3 或 flac**，看元数据）
- flac → mp3 需 ffmpeg：用 `imageio-ffmpeg` 包自带二进制，免装系统 ffmpeg

### 关键点
- `.ncm` 解出来**不一定是 mp3**，可能是 flac（本次"小小奇迹"就是 flac 36MB）
- flac 转 mp3：`ffmpeg -y -i in.flac -codec:a libmp3lame -b:a 192k out.mp3`

## 4. 环境隔离教训

- **禁止把转换依赖装进已有项目 env**（本次误装进 GAF 的 conda `gaf` 环境，随后 `pip uninstall ncmdump mutagen` 还原）
- 正确做法：建**独立 venv**，`python -m venv --clear .\venv` 后 `pip install ncmdump imageio-ffmpeg`
- venv 默认不含系统 site-packages，隔离干净

## 5. 中文文件名编码坑

- PowerShell 5.1 控制台 GBK 显示中文乱码，但文件真实名是 UTF-8，手机端正常
- 用 Python（`sys.stdout.reconfigure(encoding='utf-8', errors='replace')` 或 open with encoding）处理中文名最稳
- 脚本文件本身若含中文匹配，需存成 UTF-8（本次 `-match '鸣潮先约'` 删重复文件失败疑似编码匹配问题）

## 6. 本次实操命令行备份

```powershell
# 找到手机并枚举根目录
$shell=New-Object -ComObject Shell.Application
$mttpc=$shell.Namespace(17)
foreach($d in $mttpc.Items()){ if($d.Name -match 'Ace'){ $d.GetFolder.Items() } }

# 导出 ncm/mp3 到电脑
.\scripts\export_files.ps1 -OutDir .\export -Exts ".ncm,.mp3" -Dirs "Download"

# 转换
.\venv\Scripts\python.exe .\scripts\convert_to_mp3.py -i .\export -o .\mp3_out

# 推送铃声
.\scripts\push_ringtones.ps1 -LocalFolder .\mp3_out
```
